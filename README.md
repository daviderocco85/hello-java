# Hello Java 

L'esercizio ha l'obiettivo di configurare l'ambiente di sviluppo **Java** e realizzare il primo programma, utilizzando **JDK** e **Visual Studio Code**.


## Obiettivi

- Configurare il **JDK (Java Development Kit)** seguendo le indicazioni fornite.
- Installare e configurare le estensioni obbligatorie di **Visual Studio Code**.
- Creare un nuovo progetto Java chiamato `hello-java`.
- Creare il package `org.lessons.java`.
- Creare la classe `StampaSaluto` all'interno del package.
- Definire il metodo `main`, punto di ingresso del programma Java.
- Scrivere un'istruzione per stampare un messaggio di saluto nella console.

## Risultato atteso

Al termine dell'esercitazione, il programma dovrà essere in grado di visualizzare un messaggio di saluto nella console utilizzando il metodo `main` della classe `StampaSaluto`.

Esempio di output:

`Hello Java!`

## Bonus 

Sperimentare l'utilizzo del terminale per eseguire le operazioni di gestione del repository Git, svolgendo le stesse attività attraverso i comandi da riga di comando.

In particolare:

- Inizializzare un repository Git per l'esercizio.
- Aggiungere i file al controllo di versione con `git add`.
- Creare un commit con `git commit`.
- Collegare il repository locale a un repository remoto.
- Pubblicare l'esercizio su GitHub utilizzando `git push`.
